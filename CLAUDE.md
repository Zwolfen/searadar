# Sea Radar

## Контекст проекта

Sea Radar — локальное учебное приложение для демонстрации движения судов на карте Дуврского пролива преподавателю морской подготовки.

Текущий этап — B-01: создан минимальный каркас Next.js App Router с React и TypeScript в режиме `strict`. Приложение запускается локально на `127.0.0.1:3000` командой `npm run dev`.

## Стек

- Node.js 24;
- Next.js App Router;
- React;
- TypeScript 6.x с `strict: true`;
- npm.

## Границы текущей работы

- Реализовывать задачи только по отдельному указанию пользователя.
- Не добавлять функциональность следующих задач заранее.
- Не добавлять сервер, внешние источники данных или секреты без отдельного требования.
- Сохранять запуск приложения только на loopback.
- Не читать, не выводить и не коммитить секреты или ключи доступа.
